# 日览 1.3 界面重写

## 北极星
黎明前的玻璃天文台：一天的信息像几块被夜色照亮的玻璃板，横向翻动。

## 用户与场景
- Android 手机，360–430dp 宽，单手操作。
- 早晨出门前看天气和简报，通勤时左右滑看信息流，晚上回望日程。

## 视觉
- 底色：深靛蓝 #070912 / #0B0F1C / #121729。
- 主色：月光蓝 #B5CEFF；辅色：地平线杏桃 #F3B28B；空气色：淡紫 #C8B7EA。
- 文字：暖象牙 #F6EFE3，次级 #C6C9D8，三级 #878DA2。
- 标题用系统衬线，正文用无衬线；中文标题不套全大写英文眉标。

## 结构
- 顶部：日览字标、日期、问候、当前位置与天气摘要、刷新/设置。
- 中部：HorizontalPager 四张卡（天气 / 简报 / 信息 / 今天），两侧内边距 22dp，页间距 12dp。
- 底部：玻璃 Dock 占布局高度；页码条可点，当前页名在右。

## 玻璃配方
1. 壁纸在 IO 线程降到低分辨率并做盒式模糊，按卡片在屏幕中的位置裁切，作为背景与折射层。
2. 深靛蓝半透明渐变覆盖，保留可读性。
3. 左上月光、右下杏桃的极轻径向光。
4. 96px 噪点图平铺，叠一层细颗粒。
5. 双层边 + 顶部高光 + 底部内阴影 + 随滑动移动的斜向反光。

## 动效
- 首页一次整体入场（560ms，透明度 + 12dp 上移）。
- 翻页时卡片 0.945→1 缩放、0.74→1 透明度、10dp 位移；分类和小时条不横滚，避免抢走翻页手势。
- 底部 Dock 选中玻璃块用 spring 滑动。
