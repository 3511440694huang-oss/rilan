# 日览 1.4 · 设计说明

## 北极星

**每天换一扇窗。** 背景是必应当日照片，玻璃卡片浮在照片之上；信息仍然是主角，照片只负责让每一天有区别。

## 本版取舍

- 去掉 1.3 的深色渐变主背景，改为每日必应壁纸铺满全屏。
- 照片上叠深靛蓝夜色（顶部与底部更重，中间留出照片），保证白字和玻璃上的阅读对比。
- 四张横滑卡片保留；左右留白从 22dp 收到 10dp，页距 7dp，顶部问候区压成一行，页脚与底部 Dock 收紧，让卡片实际面积明显变大。
- 信息流分类默认折叠成一行摘要，点开才显示全部标签；选中后自动收起。
- 底部导航重做为更轻的玻璃 Dock：选中项是一团会滑动的月光，图标/文字用颜色、透明度和轻微缩放过渡，不再用方块指示器。
- 所有页面沿用 1.3 的月光蓝、地平线杏桃、淡紫和“黎明前的玻璃天文台”字体层级。

## 玻璃配方

- 背景照片：`BitmapFactory` 解码，`ContentScale.Crop`，固定 1.16 倍与 -7% 偏移。
- 玻璃折射：同一张照片在 IO 线程降到 1/5 分辨率，做两遍可分离盒式模糊，卡片绘制阶段按屏幕坐标裁切，alpha 0.46。
- 卡片本身：半透明深靛蓝渐变、细颗粒、双层边、顶部高光、底部内阴影、左上冷光/右下暖光。
- 不依赖 `Modifier.blur` / RenderEffect，API 26 也有磨砂感。

## 动效

- 壁纸切换：1100ms Crossfade，新旧壁纸不闪空。
- 翻页：卡片 scale / alpha / translationY 在 `graphicsLayer` 绘制阶段读取，不触发整页重组。
- 页码条：宽度 spring，颜色 tween，页码名称 AnimatedContent。
- 分类：`AnimatedVisibility` + spring expand/shrink，箭头旋转。
- AI 总览：加载状态、内容出现和面板高度用 AnimatedVisibility / animateContentSize。
- 导航：滑动月光 spring，选中图标缩放与上移，页面切换按方向淡入淡出。

## 验收重点

- 小屏（约 360dp 宽）上四张卡不裁切，标题和页脚不挤。
- 壁纸很亮时，顶部问候、卡片正文和底部导航仍然可读。
- 分类折叠时左右滑动不被拦截；展开后标签不与翻页手势冲突。
- 没有 API Key 时首页明确引导到设置；有 Key 时生成/错误/重试状态都能走通。
- MCP 启动、检测、复制 DSH 配置、停止的文案和状态一致。

## 未验证

本版没有在实体手机上安装启动，也没有截图复核壁纸亮度、玻璃折射和 360dp 宽度下的真实排版；以上为代码与设计层面的验收口径。
